# 💜 HerCodeGames

### Learn. Play. Code. 🚀

**HerCodeGames** is an interactive coding game designed to introduce **girls aged 8–12** to programming and computer science in a fun, playful, and approachable way.

Instead of starting with complex syntax or traditional lessons, players learn fundamental programming concepts by **playing, experimenting, solving challenges, and seeing the results of their decisions immediately.**

> Because the next generation of women in tech starts with a girl discovering that coding can be fun.

---

## 🎯 The Mission

Women are still significantly underrepresented in technology.

One way to change that is to spark curiosity **before girls start thinking that technology "isn't for them."**

HerCodeGames was created with a simple goal:

**Make girls excited about programming from an early age.**

By introducing girls between **7 and 12 years old** to programming logic through games, HerCodeGames aims to help them:

* 🧠 Develop computational thinking
* 💡 Understand basic programming logic
* 🎮 Learn through experimentation rather than memorization
* 🧩 Build problem-solving skills
* 💜 Gain confidence around technology
* 🚀 Discover that computer science can be creative and fun

The bigger vision is to inspire more girls to continue exploring technology as they grow up — eventually choosing to study computer science, engineering, or other technology-related fields and helping increase the representation of women in the tech industry.

## 🎮 How It Works

HerCodeGames transforms programming concepts into interactive challenges.

Instead of writing traditional code from day one, players control a character using programming-inspired actions and must figure out **which instructions — and in which order — will solve each challenge.**

Each level introduces a new problem.

Players experiment with actions such as:

`MOVE` → Move the character forward

`JUMP` → Jump over an obstacle

`ACTION` → Interact with the environment

The player builds a sequence of instructions and runs it to see what happens.

If the solution doesn't work?

**Try again.**

That is part of programming too. 💡

The goal is not simply to reach the end of a level — it is to start developing the way programmers think:

**Observe → Think → Build → Run → Learn → Improve**

---

## 🕹️ Gameplay

Players progress through increasingly challenging levels where they need to understand the environment and choose the correct sequence of actions.

Each completed challenge unlocks the next level, encouraging players to keep experimenting and learning.

The experience is designed around three principles:

### ✨ Simple

No previous programming experience is required.

### 🎮 Playful

Programming concepts are introduced through gameplay instead of traditional lessons.

### 🧠 Educational

Every challenge encourages logical thinking, sequencing, experimentation, and problem solving.

 
## 💡 Why I Built HerCodeGames

Technology shapes almost every part of our world, yet women remain underrepresented in many areas of the tech industry.

I believe increasing that representation doesn't start when someone applies for their first technology job.

**It starts much earlier.**

It starts when a young girl discovers that she can understand technology, create things with it, solve problems with it — and actually enjoy it.

That's why I created HerCodeGames.

I wanted to build an experience where a **8-year-old doesn't need to know what a variable, function, or algorithm is to start thinking like an engineer.**

She just needs to play.

If that experience makes even one girl think:

> *"Coding is actually fun. Maybe I could do this."*

then the project has achieved something meaningful. 💜

## 🧠 What Players Learn

HerCodeGames introduces concepts that form the foundation of programming and computer science:

* Sequential thinking
* Logical reasoning
* Problem solving
* Algorithms and instruction ordering
* Cause and effect
* Debugging through experimentation
* Computational thinking

These concepts are presented visually and interactively so children can understand the **idea behind programming before worrying about programming syntax.**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/biancam5/HerCodeGames.git
```

Navigate into the project:

```bash
cd HerCodeGames
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL displayed in your terminal.
